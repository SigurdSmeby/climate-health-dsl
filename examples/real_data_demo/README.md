# Real-data demo — simulating datasets from real CHAP climate

This folder shows the DSL generating several synthetic and semi-synthetic
datasets from **real climate data** taken from the CHAP project (the
[chap-core](https://github.com/dhis2-chap/chap-core) `example_data` folder).
Each demo is one scenario file; together they show the range of what the tool
can do.

## Running a demo

```bash
dsl run examples/real_data_demo/01_vietnam_multiprovince.yaml --plot
```

No `-o` is needed. Without it, the run writes to an auto-named folder under
`out/` in your current directory (`out/01_vietnam_multiprovince/`), and a
second run goes to `out/01_vietnam_multiprovince_1/` — so re-running never
overwrites a previous run. Pass `-o some/dir` only if you want to choose the
location explicitly.

The `output/` folder here holds **pre-generated reference output** for each
demo (CSV, `metadata.json`, and an interactive `plot.html`) so you can see the
results without running anything. Re-running a demo does not touch it.

## The bundled real climate (in `examples/data/`)

The real CSVs live one level up in `examples/data/`, and the scenarios here
reference them as `../data/<file>`:

| File (`examples/data/`) | Source | Contents |
|---|---|---|
| `vietnam_provinces.csv` | chap-core `vietnam_monthly.csv` | Monthly rainfall, temperature, cases, population for 4 Vietnamese provinces (An Giang, Dak Lak, Ha Giang, Khanh Hoa), 2000–2009. |
| `brazil_adamantina.csv` | chap-core `monthly_data.csv` | Monthly temperature and cases for Adamantina (São Paulo, Brazil), 2012–2019. |
| `laos_subset.csv` | chap-core `laos_subset.csv` | Monthly rainfall, temperature, cases, population for 3 Lao provinces, 2010–2012. |

Each was trimmed to a clean, consecutive window to keep the files small. Only
the **climate** columns are used as real input; the disease signal in every
demo is generated by the DSL with a *known* relationship — that's the point:
you control the ground truth.

## The demos

### 1. `01_vietnam_multiprovince.yaml` — real multi-province climate
Real Vietnam rainfall and temperature drive a synthetic dengue-like signal
across four provinces, each with its own population, sharing one controlled
relationship (rainfall lag 2, temperature lag 1). Overdispersed
(negative-binomial) counts, 80/20 train/test split.
*Shows: `from_csv` real covariates, multi-location with per-location
population, negative-binomial counts, train/test split.*

### 2. `02_brazil_real_temperature.yaml` — mix real and synthetic covariates
Real Brazil temperature is paired with a **synthetic** monsoon rainfall
covariate in the same scenario; disease depends on both, and the population
**grows** over the eight years via the `linear_trend` generator.
*Shows: combining a real `from_csv` covariate with a fully synthetic one, plus
time-varying population.*

### 3. `03_fully_synthetic_vietnam_like.yaml` — fully synthetic, tuned to look real
No real data is read. The climate is generated to *resemble* the Vietnam
statistics (monsoon rainfall, ~27 °C temperature), with the same known lags,
across three locations — plus a flat **decoy** covariate the disease ignores.
*Shows: synthetic generators tuned to real statistics, independent per-location
draws, a control/decoy variable, missing data.*

### 4. `laos_real_climate_from_csv.yaml` — real Laos climate, synthetic disease
Reads real Bokeo-province rainfall and temperature from `laos_subset.csv` and
generates disease on top. The simplest semi-synthetic example.
*Shows: a minimal real-climate `from_csv` scenario.*

### 5. `laos_fully_synthetic.yaml` — fully synthetic, tuned to the Laos data
The synthetic counterpart to #4: all columns generated, parameters matched to
the real Laos statistics, with per-province growing populations.
*Shows: fully synthetic climate tuned to real data, time-varying per-location
population.*

## What each run produces

Every run writes `simulated_data.csv` (CHAP-ready), a `metadata.json` recording
the exact ground truth (seed, lags, weights, generators — enough to reproduce
the dataset), and with `--plot` an interactive `plot.html`. Demos that set
`train_fraction` also write `train.csv`/`test.csv`.

## A note on per-location real climate

`from_csv` binds one `source_location`, so in demo 1 every output province gets
the *same* real climate (the tool warns about this). Per-location real climate
mapping is a planned feature; for now demo 1 differs by population, and demos 3
and 5 show independent synthetic climate per location.
